# 生成逐词歌词时间

先读取[共享执行协议](../pv-plan/references/protocol.md)，确定工程根目录、任务目录和当前授权范围。独立调用时也检查本阶段前置产物；状态未创建则交 `$pv-plan` 初始化，不把本项目原歌数据自动当作新歌数据。

## 输入

完整中间数据、当前语言的词元/发音规则。

## AI 执行

检查pron映射、字符表、全曲帧长度和人工FIX是否属于当前歌。用融合概率做整曲Viterbi，star词元吸收未列出的和声/即兴片段；根据能量/起音/辅音及长音精修。
执行 uv run --frozen python align.py --plots；检查输出文本、词序、时间范围、置信度与音节区间。不能把置信度数值描述为已校准的统计准确率。
明确低置信度和模型分歧位置，生成问题清单；自动结果只是待审数据。不要静默采用旧歌FIX，或仅为满足不重叠而掩盖唱词错误。

## 产物与完成条件

data/lyrics.json、align_debug.json、逐行QA图、alignment.md与疑难词表。

输出与源歌词逐词一致，时间有效；歧义未被隐藏；完成检查不等于主观同步已通过。

## 需要人提供什么

真正听不清、歌曲与歌词不一致且AI无法判定时，请用户确认具体词或演唱版本。
