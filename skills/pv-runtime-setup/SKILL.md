# 安装基础运行工具

先读取[共享执行协议](../pv-plan/references/protocol.md)，确定工程根目录、任务目录和当前授权范围。独立调用时也检查本阶段前置产物；状态未创建则交 `$pv-plan` 初始化，不把本项目原歌数据自动当作新歌数据。

## 输入

环境审计和已授权的安装范围。

## AI 执行

读取环境安装参考，优先复用兼容版本。分析任务用 uv 管理满足项目依赖的 Python（>=3.12），需要时执行 uv python install 3.12；渲染任务准备 Bun、ffmpeg libx264 和实际 Google Chrome。
从官方文档或现有包管理器确定当前平台命令，安装前检查下载来源和目标路径；不覆盖现有浏览器、不修改系统 Python、不擅自改 shell 启动配置。正常项目依赖安装属于已授权制作范围，无需反复请求许可；受沙箱/系统权限限制时按工具权限处理。
网络失败先保留日志，确认原因后作有限重试，不反复执行同一个失败下载。只安装本次所需组件；离线时使用用户已有安装包或镜像，继续独立的概念工作。

## 产物与完成条件

runtime-setup.md：实际执行命令、安装路径/版本、平台适配和未解决项。

运行版本检查；ffmpeg -encoders 确认 libx264；浏览器实际可启动的验证留给渲染依赖阶段。

## 需要人提供什么

工具明确拒绝权限、只有系统管理员能安装的组件、或必须提供离线安装包时。

## 交接

按共享协议把实际验证、输入指纹、产物和剩余问题写入阶段报告，再登记状态。分析走 pv-python-setup；视频走 pv-renderer-setup。
